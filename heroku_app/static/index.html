Модель-картка · методологія

Задача. Бінарна класифікація ймовірності з reject-option (selective classification): Post / Do-not-post / Unsure до публікації; Keep / Delete через день-1. «Unsure» — каліброване визнання невпевненості, не окремий клас.

Мітка. «Breakout within-creator» @ H=14 — чи відео перевершило медіану власного автора. Fame-neutral: класифікатор лише на розмірі аудиторії дає AUC ≈ 0.51 (перевірено).

Чесна стеля. До публікації задача інформаційно обмежена (перші секунди утримання, алгоритм, тренд — не видно): Model A ≈ 0.58, і сильніша модель її не рухає. День-1 сигнал підіймає Model B до ≈ 0.75 — там надійне рішення.

Дисципліна. Нуль post-publication метрик на вхід Model A; усе fit лише на train; leave-one-creator-out + temporal спліти; bootstrap 95% CI. Ці моделі — 33 прості hand-фічі (текст, час, тривалість), torch-free.
