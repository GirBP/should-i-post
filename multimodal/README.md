# Мультимодальний трек: реальні TikTok-відео + аудіо + текст

**Мета.** Пробити інформаційну стелю передпублікаційної оцінки (~0.55 на метаданих), додавши
те, чого бракує: **сам відеоконтент і аудіо**. Це не drop-in поверх lingbow — lingbow дає лише
похідні текстові ознаки, тож ми **докачуємо реальні відео за `video_id`** і будуємо повний
мультимодальний пайплайн.

## Чому так (а не готовий набір)

Окремого дослідницького набору TikTok із самими відеофайлами немає — ToS дозволяє публікувати лише
ID. Стандарт: узяти ID (у нас 209k реальних TikTok-відео з lingbow + наші мітки/панель) і докачати
mp4 локально (yt-dlp). Дані lingbow за 2024-06..11, тож станом на 2026 частина відео видалена →
**покриття буде неповним** (очікуй умовно 40–70%); працюємо з тим, що завантажилось.

## Пайплайн (усе локально, Mac MPS/CPU)

```
brew install ffmpeg
python -m venv .venv && source .venv/bin/activate
pip install -r multimodal/requirements.txt

python multimodal/01_download_videos.py --limit 500   # проба покриття
python multimodal/01_download_videos.py               # повний маніфест (15k)
python multimodal/02_extract_features.py              # кадри→CLIP, аудіо→мел, текст→MiniLM
python multimodal/03_train_eval.py                    # Модель A (абляція) + Модель B, метрики
```

Артефакти: `data/videos/*.mp4`, `data/multimodal/features.parquet`,
`reports/multimodal_metrics.json`.

## Що рахуємо

- **Відео:** 8 рівномірних кадрів + окремо «гачок» (перші 3 с) → CLIP ViT-B/32 → ембедінги.
- **Аудіо:** лог-мел статистики (mean/std) через ffmpeg+librosa (легко, без важких моделей).
- **Текст:** desc+gpt_summary+transcript (lingbow) → MiniLM.
- **Мітка:** breakout (within-creator) із маніфесту; оцінка **LOCO** (за авторами) + темпоральна.

## Чого очікувати (чесно)

- Реалістичний приріст Моделі A над табличним baseline: з ~0.55 до приблизно **0.60–0.68**
  (література для чисто передпублікаційного мультимодалу ~0.6–0.7). Це помітно, але не «оракул».
- Найбільше зазвичай дає **гачок** (перші секунди) і семантика; аудіо — менше.
- Модель B (+доба) лишається найсильнішою — мультимодал головно покращує саме передпублікаційну A.
- Стелю обмежує те, чого не дають дані: алгоритмічний сидинг і зовнішні тренди.

## Ресурси / масштаб

- 15k відео: завантаження кілька годин (мережа), екстракція кадрів/CLIP на Mac MPS — орієнтовно
  кілька годин. Можна почати з `--limit` і нарощувати. CLIP/MiniLM ваги тягнуться один раз.
- Поважай ToS і приватність: лише дослідження/прототип, відео не перерозповсюджувати.

## Структура

