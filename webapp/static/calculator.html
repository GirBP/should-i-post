Self-learning

Track this posted video: the system polls its public stats, freezes the day-1 signal, self-labels it after 14 days against the creator's own median, and the accumulated labels retrain a challenger model (champion is replaced only after human review).

Day-1 data (optional — switches to Model B)

In URL mode Model B activates automatically when a genuine day-1 signal exists — a tracked 24h snapshot, or a video that is ~1 day old (current counts ≈ day-1). Fill these fields only to override. Enter the counts at the 24-hour mark only: for an old video the URL shows current cumulative counts, not day-1, so typing those gives Model B out-of-distribution input. True day-1 comes from Track for self-learning (snapshots at 24h).
