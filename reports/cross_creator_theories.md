# Чи переноситься знання інших креаторів на наше відео (до публікації)?

**Питання:** чи можна з досвіду інших авторів витягнути знання, що оцінює наше відео ще на старті.

**Метод (коректний тест переносу):** оцінка з розбиттям за авторами — GroupKFold (4 фолди),
де тестового автора **немає** в навчанні (leave-one-creator-out, LOCO). Якщо AUC > 0.5 — знання
чужих креаторів реально переноситься. Мітка: breakout (within-creator), бінаризована по медіані.
База: 207 509 придатних відео, base rate 0.503. Усі попередні ознаки (тема/музика/хештеги) кодуються
**fold-safe** (лише з train-авторів), без витоку. Дані: `reports/cross_creator_theories.csv`.

## Результати (LOCO AUC: чужі автори → наш)

| Теорія | LOCO AUC |
|---|---|
| Семантика (про що відео: gpt-резюме + транскрипт, SVD60) | **0.557** |
| Усі теорії разом (HGB) | 0.544 |
| Хештеги (track-record тегів у інших) | 0.524 |
| Тема/ніша (cross-creator base rate) | 0.520 |
| Підпис/гачок (патерни тексту) | 0.517 |
| Музика (prior + популярність звуку) | 0.515 |
| Час публікації | 0.509 |
| Емоції / arousal (Berger–Milkman) | 0.508 |
| Тривалість | 0.507 |

(випадковість = 0.500)

## Висновки

1. **Знання інших креаторів переноситься, але слабко.** Усі теорії вищі за 0.5 — сигнал реальний
   і ненульовий, але жодна не сильна (0.51–0.56). Це не оракул, а слабкий пріор.

2. **Найбільше переноситься «про що відео»** — семантика (0.557) і похідні: хештеги (0.524) і
   тема/ніша (0.520). Тобто головне переносне знання = *який сюжет/ніша/теги заходять у інших*.

3. **«Фолклор» переноситься найгірше.** Найкращий час публікації (0.509), ідеальна тривалість
   (0.507) і емоційний тон (0.508) майже не узагальнюються між авторами — це або специфіка
   аудиторії конкретного автора, або шум. Важливо: типові «universal best practices» про час/довжину
   тут даними **не підтверджуються**.

4. **Сигнали не складаються.** Зведена модель (0.544) не краща за саму семантику (0.557) — багато
   слабких ознак додають радше шум.

## Що це означає для продукту

- З чужого досвіду можна взяти **невеликий реальний edge** (~0.55 AUC) — переважно «тема/семантика/
  хештеги», а не час/довжина/емоції. Цього достатньо, щоб **підказувати і тріажити**, але не щоб
  впевнено гейтити рішення.
- Вирішальний сигнал лишається у власній **першій добі** автора (Модель B, ~0.94 на breakout-wc).
- Наступний, ще не випробуваний важіль — **creator-fit** (схожість кандидата на власні минулі хіти
  автора). Це не cross-creator, а within-creator перенос. Варто перевірити окремо.
